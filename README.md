## What I'm Building

### AI & LLM Projects
- **[Maintenance Report Generator](https://github.com/Scott-dot/maintenance-report-generator)**  
  Data-to-narrative pipeline: work order data → aggregation → LLM narration →
  styled HTML report. Demonstrates prompt engineering and LLM integration in a
  data engineering context.

- **[RAG Q&A System](https://github.com/Scott-dot/rag-qa-system)**  
  Retrieval-augmented generation pipeline: document ingestion → ChromaDB vector
  storage → semantic retrieval → locally-hosted LLM answer generation.

- **[Synthetic Data Generator](https://github.com/Scott-dot/synthetic-data-generator)**  
  Two-stage LLM pipeline: plain English description → schema design → data
  generation. Guided and random modes, configurable dirty data injection,
  schema validation and JSON recovery.

- **[LLM Report Generator](https://github.com/Scott-dot/llm-report-generator)**  
  First AI project: CSV data → local LLM → generated narrative report.
  Demonstrates basic LLM integration in a data reporting context.
